## 📂 폴더 구조

```
날짜(문제이름_문제번호)/
├── README.md          # 그 주의 문제, 일정, 과제
└── 깃허브닉네임/
    ├── 풀이 파일       # 예: solution.py, Solution.java
    └── 이론정리.md     # 이론 과제가 있는 주만
```

- 폴더 이름에는 공백을 넣지 않습니다. 예: `2026.12.02(카카오앱정리하기_468374)`
- 문제가 정해지기 전 주차는 `날짜(문제미정)`으로 두고, 문제가 정해지면 이름을 바꿉니다.

## ✅ 규칙

1. **자기 닉네임 폴더에만** 파일을 올립니다.
2. 모임 전까지 풀이(와 이론 정리)를 push합니다.
3. 모임에서 각자 어떻게 풀었는지 설명합니다.
